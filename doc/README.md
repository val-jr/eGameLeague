# OBJETIVO

O projeto LoginEGameLeague tem como objetivo a realização do cadastro e login dos participantes dos campeonatos.

# ESTRUTURA DO PROJETO

As três classes principais são

**Login**: armazena os dados de login e validar as credenciais do usuário.

**Menu**: representa a interface, simples, onde o usuário coloca suas informações.

**Usuario**: representa a conta do usuário, com dados como nome e id.

# MODELOS

Armazena as classes principais e guarda os atributos, regras e comportamentos básicos das respectivas classes, que são acessados por meio dos getters e setters.
