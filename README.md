# 🎮 eGameLeague - Sistema de Gestão de Campeonatos de eSports

Bem-vindo ao repositório oficial do **eGameLeague**, um sistema completo para organização e gerenciamento de torneios de eSports, desenvolvido como parte das UCs de **Programação de Sistemas Computacionais** e **Sistemas Computacionais e Segurança**.

Este projeto utiliza **Java** e **JavaFX** para criar uma interface gráfica interativa, permitindo o cadastro de times, criação de partidas, geração de tabelas e análise de estatísticas.

---

## 🚀 Sobre o Projeto

### **Objetivo**

O **eGameLeague** foi desenvolvido para proporcionar uma experiência prática em desenvolvimento colaborativo, aplicando conceitos de programação orientada a objetos, banco de dados e interfaces gráficas. O sistema é voltado para a gestão de campeonatos de eSports, como FIFA, CS:GO, LoL e Valorant, e permite:

- Cadastro de times e jogadores.
- Criação e gerenciamento de torneios.
- Geração automática de tabelas e confrontos.
- Análise de estatísticas e rankings.

### **Por que esse projeto é ideal?**

- **JavaFX** é perfeito para criar painéis interativos, dashboards e tabelas de partidas.
- O tema de **eSports** é atrativo e relevante para o público jovem.
- A divisão em **squads** permite um desenvolvimento organizado e colaborativo.

---

## 🔥 Divisão do Projeto e Squads

O projeto foi dividido em módulos, cada um desenvolvido por um squad específico. Abaixo estão os squads e suas responsabilidades:

### **1️⃣ Squad 1 - Autenticação e Gestão de Usuários**

- Desenvolvimento do sistema de login e cadastro de usuários.
- Diferenciação de permissões (admin, jogadores).
- **Tecnologias:** Java, JavaFX (Telas de Login e Perfil), JDBC, SQL.

### **2️⃣ Squad 2 - Cadastro e Gerenciamento de Torneios**

- CRUD de torneios (nome, data, tipo: solo, duo, squad).
- Definição de regras (eliminação simples, fase de grupos, pontos corridos).
- **Tecnologias:** Java, JavaFX (Tela de Gerenciamento de Torneios), JDBC, SQL.

### **3️⃣ Squad 3 - Tabelas e Partidas**

- Geração automática de tabelas e confrontos.
- Registro de resultados e atualização da classificação.
- **Tecnologias:** Java, JavaFX (Tela de Partidas e Tabelas), JDBC, SQL.

### **4️⃣ Squad 4 - Ranking e Estatísticas**

- Exibição de rankings de times/jogadores por torneio.
- Análise de estatísticas de desempenho (vitórias, derrotas, KD Ratio).
- Exportação de relatórios para CSV ou PDF.
- **Tecnologias:** Java, JavaFX (Tela de Estatísticas), JDBC, SQL.

### **5️⃣ Squad 5 - Interface e Experiência do Usuário**

- Construção da interface principal com menus e navegação.
- Integração com os módulos dos outros squads.
- Personalização com temas visuais e animações.
- **Tecnologias:** Java, JavaFX (Tela Principal e Dashboard), JDBC.

## 📌 Metodologia de Trabalho

- Cada squad é responsável por um módulo específico, mas deve garantir integração com os demais.
- **Integração semanal:** Reuniões para testar a comunicação entre os módulos.
- **Versionamento:** Utilização do GitHub para controle de versões e colaboração.
- **Entrega final:** Demonstração funcional do sistema e apresentação dos squads.

## 🚀 Como Executar o Projeto

### **Pré-requisitos**

- JDK 21 ou superior.
- IDE de sua preferência (recomendado: IntelliJ IDEA).
- Banco de dados configurado (PostgreSQL, etc.).

### **Passos para Execução**

1.  Clone o repositório:

    bash

    Copy

    git clone https://github.com/eGameLeague/egame-league.git

2.  Importe o projeto na sua IDE.
3.  Configure o banco de dados e atualize as credenciais no arquivo de configuração.
4.  Execute o projeto a partir da classe principal.
